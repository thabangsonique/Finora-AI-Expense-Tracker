# AI Expense Tracker App

A full-stack expense tracker built with Expo, React Native, Expo Router, Nativewind, and a simple Express backend.

## Project Overview

This project includes:

- `Finora/`: Expo app with file-based routing and tab navigation
- `Backend/`: Express server for API and backend logic

The mobile app uses Expo Router and Nativewind for styling, while the backend is a lightweight Express server with JSON parsing and CORS.

## Features

- Expo Router file-based navigation
- Bottom tab navigation for primary app screens
- Nativewind / Tailwind CSS styling
- Sign-in screen and authenticated route structure
- Express backend ready for future API endpoints

## Tech Stack

- Expo
- React Native
- Expo Router
- Nativewind
- Tailwind CSS
- Express
- CORS
- dotenv
